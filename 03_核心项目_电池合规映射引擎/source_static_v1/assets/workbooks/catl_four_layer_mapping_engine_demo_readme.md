## Sheet 结构
1. `01_手动输入`：唯一允许手动修改的输入表。
2. `02_欧盟电池法输出`：自动输出 EU Battery Regulation 结果。
3. `03_CBAM输出`：自动输出 CBAM-compatible 结果。
4. `04_字段映射过程`：字段怎么从 CATL 口径转成 EU/CBAM 口径。
5. `05_证据映射过程`：每个输出字段背后需要什么证据。
6. `06_核验映射过程`：谁来确认这些字段。
7. `07_权限映射过程`：谁能看哪些字段。
8. `08_生命周期计算过程`：生命周期碳足迹与 CBAM 影子模块计算过程。
9. `09_EU中间表`：EU 输出预览中间表。
10. `10_CBAM中间表`：CBAM 输出预览中间表。
