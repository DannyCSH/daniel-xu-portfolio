# 增强版功能说明

## 概述

增强版前端在原有静态 demo 基础上，增加了以下交互功能，方便比赛展示和团队审查。

## 新增文件

- `frontend/index-enhanced.html` - 增强版入口页面
- `frontend/styles-enhanced.css` - 增强版样式
- `frontend/app-enhanced.js` - 增强版交互逻辑

## 功能说明

### 1. 角色切换

三种预设角色，不同角色看到的数据范围不同：

| 角色 | 能看到的内容 |
|------|------------|
| 查看者 | 仅公开披露的数据 |
| 审核者 | 公开数据 + 证据链，可标注缺口 |
| 管理员 | 全部字段，含内部/受限数据 |

**使用方式**：点击侧边栏的角色按钮切换。

### 2. 视图切换

支持表格视图和卡片视图两种展示模式：

- **表格视图**：紧凑展示，适合详细审查
- **卡片视图**：每行数据一张卡片，更直观

**使用方式**：点击工具栏的"表格"/"卡片"按钮切换。

### 3. 字段筛选

支持按数据类型筛选：

- **全部字段**：展示所有数据
- **可直接引用**：CATL 现有公开披露可直接继承的字段
- **需要拆分**：公司级数据需要继续拆到产品/工厂/供应商级的字段
- **存在缺口**：当前 demo 存在数据缺口的部分

**使用方式**：点击工具栏的筛选按钮。

### 4. 证据链展示

针对关键数据字段，提供完整的证据链追溯视图：

- 碳足迹强度证据链
- 铝材 CBAM 兼容证据链
- 钢材 CBAM 兼容证据链
- 再生材料证据链
- 供应链追溯证据链

**使用方式**：在 EU 输出或 CBAM 输出表格中，点击"查看证据链"按钮。

### 5. 四层映射展开

四层映射卡片支持点击展开/收起，方便深入了解每层的具体逻辑。

## 与原版的关系

- 增强版与原版功能并行，不影响原版展示
- 如需切换回原版，使用 `index.html` 而非 `index-enhanced.html`
- 后续开发建议在增强版基础上继续迭代

## 技术说明

- 零新增外部依赖，保持轻量化
- 状态管理使用简单的 `state` 对象
- 角色权限通过 `roleConfig` 配置对象管理
- 证据链数据通过 `evidenceData` 对象存储
