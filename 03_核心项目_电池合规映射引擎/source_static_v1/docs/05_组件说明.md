# 组件说明

## 文件结构

```
frontend/
├── index.html              # 原版入口
├── index-enhanced.html     # 增强版入口
├── styles.css              # 原版样式
├── styles-enhanced.css    # 增强版样式
├── app.js                  # 原版逻辑
├── app-enhanced.js         # 增强版逻辑
└── data/
    └── demo-data.js        # 演示数据
```

## 核心组件

### 1. RoleSwitcher 角色切换器

**位置**：`app-enhanced.js` 的 `renderRoleSwitcher()` 函数

**功能**：渲染三种角色的切换按钮

**配置**：`roleConfig` 对象

```javascript
const roleConfig = {
  viewer: { label: '查看者', showEvidence: false, ... },
  auditor: { label: '审核者', showEvidence: true, ... },
  admin: { label: '管理员', showConfidential: true, ... }
};
```

### 2. ViewModeToggle 视图模式切换

**位置**：`app-enhanced.js` 的 `renderViewModeToggle()` 函数

**功能**：在表格视图和卡片视图之间切换

### 3. FilterBar 筛选栏

**位置**：`app-enhanced.js` 的 `renderFilterBar()` 函数

**功能**：按数据类型筛选字段

**筛选逻辑**：`fieldPermissions` 对象定义每种筛选类型包含的字段

### 4. EvidenceModal 证据链弹窗

**位置**：`app-enhanced.js` 的 `renderEvidenceModal()` 函数

**功能**：展示完整的数据证据链

**数据结构**：`evidenceData` 对象存储各字段的证据链

```javascript
evidenceData = {
  'carbon_intensity': {
    title: '碳足迹强度证据链',
    items: [
      { type: 'input', name: '...', desc: '...' },
      { type: 'calc', name: '...', desc: '...' },
      { type: 'evidence', name: '...', desc: '...' },
      { type: 'output', name: '...', desc: '...' }
    ]
  }
}
```

### 5. DataTable 数据表格

**位置**：`app-enhanced.js` 的 `createTable()` 函数

**功能**：渲染可筛选、可高亮的数据表格

### 6. CardView 卡片视图

**位置**：`app-enhanced.js` 的 `createCardView()` 函数

**功能**：以卡片形式展示数据，每行数据一张卡片

## 状态管理

全局状态对象 `state`：

```javascript
const state = {
  currentView: 'overview',    // 当前视图
  currentRole: 'viewer',      // 当前角色
  currentProduct: '...',      // 当前产品
  filterType: 'all',         // 筛选类型
  viewMode: 'table',         // 视图模式
  expandedEvidence: null,    // 展开的证据链
  activeLayer: null          // 展开的四层映射卡片
};
```

## 权限系统

通过 `fieldPermissions` 对象定义字段权限：

```javascript
const fieldPermissions = {
  directUse: ['field1', 'field2', ...],    // 可直接引用
  needSplit: ['field3', 'field4', ...],    // 需要拆分
  confidential: ['field5', ...]            // 受限字段
};
```

## 扩展建议

1. **新增角色**：在 `roleConfig` 中添加新角色配置
2. **新增筛选**：在 `fieldPermissions` 中添加新字段分类
3. **新增证据链**：在 `evidenceData` 中添加新字段的证据链
4. **新增视图**：在 `sections` 对象中添加新视图区块
