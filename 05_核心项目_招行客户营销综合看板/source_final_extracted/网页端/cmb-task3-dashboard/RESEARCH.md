# 联网调研与数据源建议

调研日期：2026-07-17。以下网站均在制作原型时在线核验了可访问性或作为官方入口确认。

## 官方与公开来源

- [国家统计局国家数据](https://data.stats.gov.cn/)：宏观经济、工业、价格、投资等指标。适合补充外部环境、供需和价格传导维度。更新频率依指标而定，不应统一标记为“实时”。
- [深圳政府在线](https://www.sz.gov.cn/)：深圳市及各部门政策、产业规划、专项申报通知和政策解读。适合政策雷达与属地政策契合度。
- [中国人民银行](https://www.pbc.gov.cn/)：金融统计、货币政策与金融支持实体经济相关公开信息。适合宏观金融环境和行业融资条件解释。
- [国家发展和改革委员会](https://www.ndrc.gov.cn/)：产业政策、设备更新、价格监测和发展规划。适合外部环境及政策冲击分析。
- [巨潮资讯](https://www.cninfo.com.cn/)：上市公司公告、年报和重大事项。适合产能、订单、资本开支和经营信号抽取。
- [国家企业信用信息公示系统](https://www.gsxt.gov.cn/)：企业登记、经营状态和行政处罚等信息。生产使用需取得合规授权并遵守访问限制。

## 实时源设计

赛题二要求至少一个动态实时数据源。建议按所选产业链采购或接入合规 API，而不是在答辩原型中依赖不稳定的网页抓取：

- 半导体：关键金属、硅料、存储芯片或电子元器件价格指数。
- 新能源汽车：锂、镍、钴、碳酸锂现货/期货价格和动力电池装机数据。
- 机器人：钢、铜、稀土永磁价格，以及制造业 PMI/工业机器人产量的最新发布。
- 生物医药：集采、审评审批、临床试验登记和重点原料价格。
- 低空经济：招投标、空域/场景开放、无人机登记或重点项目开工信息。

实时接入必须保存 `source_id`、原始 URL/API、抓取时间、数据时间、重试状态和哈希；失败时展示“数据延迟”，不能沿用旧值伪装为实时。

## 看板设计结论

1. 地图只是入口，不是最终结论。地图点击后必须下钻客户，避免停留在区域热力展示。
2. 产业景气度必须可解释。总分旁边同时展示六维结构、趋势预测、链上节点和风险信号。
3. 政策不能只做文档列表。需要结构化为地区、产业链、节点、扶持方式、申报条件和时效，再映射存量客户。
4. 客户画像必须把任务一和任务二放进同一决策面：预测额度回答“能做多少”，产业层级和景气回答“是否值得做、何时做”。
5. 最终交付应闭环到营销任务、产品组合、客户经理和效果复盘，否则看板仍是分析展示，不是业务落地工具。
