# 链策智营：赛题三客户营销综合看板

这是一个可离线运行的高保真 HTML 原型，入口为 `index.html`。页面已内置 ECharts、Lucide 图标、全国与深圳行政区地图，不需要安装前端依赖。

由于浏览器不允许 `file://` 页面读取本地 GeoJSON，请在项目目录启动任意静态文件服务：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8765/`。

## 已实现的业务链路

1. 全国网点：全国地图、省会节点、属地网点下钻，以及支行/企业统一搜索。
2. 支行总览：支行管辖半径、五大产业切换、企业分层与授信等级、景气排行、政策匹配和三类经营分析。
3. 行业洞察：六维景气模型、趋势预测、产业链图谱、断链风险和企业分层。
4. 政策雷达：政策情报流、产业影响热度、政策与存量客户匹配、申报窗口提醒。
5. 客户中心：客户 360° 画像、企业位置、联系电话、拜访提醒、可信依据和可执行建议。
6. 营销工作台：转化漏斗、行动清单、战役看板和任务创建。
7. AI 经营助手与数据血缘：基于当前上下文回答经营问题，并展示模型口径和替换来源。

地图点位、企业名称、经营指标、模型评分和政策标题均为演示样例，不代表招商银行真实客户或经营结论。

## 真实数据替换

| 页面 | 当前样例 | 生产接入 |
| --- | --- | --- |

| 营销工作台 | 本地交互状态 | CRM 任务、客户经理、触达记录、商机阶段、审批结果和效果反馈 |

## 推荐接口边界

- `GET /api/branches/{id}/overview`：区域经营指标和行政区聚合。
- `GET /api/industry-chains/{id}/prosperity`：景气总分、六维评分、趋势与解释。
- `GET /api/industry-chains/{id}/graph`：产业链节点、交易关系和断链风险。
- `GET /api/customers/{uid}/portrait`：单客 360° 画像与任务一/任务二结果。
- `GET /api/policies?region=&industry=`：政策列表、时效、标签和匹配客户数。
- `POST /api/marketing/campaigns`：创建战役并保存圈选口径。
- `POST /api/marketing/tasks`：创建客户跟进任务。
- `POST /api/copilot/query`：带机构、产业链、客户 UID 和数据版本的 Agent 查询。

## 演示建议

答辩时按以下顺序点击：全国网点搜索“南山支行” → 支行总览切换产业链 → 点击企业点位 → 客户 360° 画像 → 加入拜访日程。然后用行业洞察解释“为什么选这条链”，再用政策雷达解释“为什么是现在”。
